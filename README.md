# 📸 MS_helper

Портативный инструмент для наведения порядка в фото- и видеоархивах: сортировка по дате съёмки (EXIF/ffprobe), автопереименование, поиск дубликатов по MD5, выделение мусора и реорганизация структуры архива по годам и месяцам. GUI + CLI, работает без установки.

## Возможности

- **Сортировка по дате съёмки** — дата из EXIF (фото), ffprobe (видео) или имени файла; автопереименование `IMG_20200325_114014.jpg` → `2020-03-25_11-40-14.jpg` (чек-бокс «Переименовать по дате съёмки», отключается флагом `--no-rename`)
- **Дубликаты по MD5** — в папку `Дубликаты`, файлы не перезаписываются (суффиксы `_1`, `_2`)
- **Мусор** — настраиваемые пороги: фото по размеру (КБ), видео по длительности (сек) и/или размеру (КБ) → папка `Мусор`
- **Файлы без даты** — папка `Без данных` (подпапки `photo`/`video`)
- **Мессенджеры** — распознавание файлов WhatsApp / Telegram / Viber
- **Реорганизация архива** — автоопределение уровня (корень / год / месяц), переименование папок, разделение на `*_photo` и `*_video`
- **Безопасность** — пробный прогон `--dry-run`, подтверждение перед изменениями
- **GUI-лаунчер** на Tkinter + CLI; результаты сортировки — в подпапку `MS_helper` внутри выбранной папки назначения

## Запуск (Python уже внутри)

Python 3.11.9 со всеми библиотеками лежит в папке `python\` — устанавливать
ничего не нужно. Программа работает с флешки, сетевой папки, любого ПК.

**Запуск:**

- двойной клик по `run.bat` — окно без консоли;
- двойной клик по `launcher.vbs` — то же самое;
- или ярлык `MS_helper` в корне проекта (создаётся один раз).

**Ярлык на рабочем столе** (один раз, на каждом новом компьютере):

```cmd
python\python.exe create_shortcut.py
```

Ярлык хранит абсолютный путь, поэтому при переносе папки его нужно создать
заново — это ограничение формата `.lnk` в Windows.

**Проверка, что всё на месте:**

```cmd
python\python.exe -c "import PIL, pillow_heif, exifread, tqdm, ffmpeg; print('OK')"
```

Если видите `OK` — библиотеки на месте и версии совместимы.

### Видео

Для точных дат видео нужен `ffprobe.exe` из пакета ffmpeg. Положите его
в папку `bin\` — она переносится вместе с проектом. Без ffprobe видео
сортируются по имени файла и дате изменения, для `.mp4` с телефона обычно
этого достаточно.

### Обновление после сортировки

Когда сортировка завершена, программа предложит подготовиться к новой:
нажмите «Да» — поля очистятся, и можно выбирать другие папки.
Кнопка **«Обновить»** делает то же самое в любой момент.

Кнопка **«Сбросить всё»** дополнительно удаляет отчёт и логи прошлого прогона.
Папка `python\`, исходный код и ассеты не удаляются никогда.

## Запуск с системным Python (для разработки)

```bash
pip install -r requirements.txt
```

Для метаданных видео нужен `ffprobe` (из пакета ffmpeg) — добавьте его в `PATH`
или положите `ffprobe.exe` в папку `bin\` (она тоже переносится вместе с проектом).

## Использование

```bash
# Сортировка по дате
python sort_media.py -s "D:\Фото\Несортированные" -d "D:\Фото\Sorted" --check-duplicates --yes

# Реорганизация архива (пробный прогон)
python reorganize_media.py -r "D:\Фото\Архив" --dry-run

# GUI-лаунчер
python launcher.py

# GUI-лаунчер без окна консоли (Windows)
wscript.exe launcher.vbs
```

> В GUI результаты сортировки помещаются в подпапку `MS_helper` внутри выбранной папки назначения.
