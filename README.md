# 📸 MS_helper

Портативный инструмент для наведения порядка в фото- и видеоархивах: сортировка по дате съёмки (EXIF/ffprobe), автопереименование, поиск дубликатов по MD5, выделение мусора и реорганизация структуры архива по годам и месяцам. GUI + CLI, работает без установки.

## Возможности

- **Сортировка по дате съёмки** — дата из EXIF (фото), ffprobe (видео), имени файла или mtime; автопереименование `IMG_20200325_114014.jpg` → `2020-03-25_11-40-14.jpg`
- **Дубликаты по MD5** — в папку `Дубликаты`, файлы не перезаписываются (суффиксы `_1`, `_2`)
- **Мусор** — фото ≤ 2 МБ и видео длительностью ≤ 10 секунд → папка `Мусор`
- **Файлы без даты** — папка `Дата_не_определена`
- **Мессенджеры** — распознавание файлов WhatsApp / Telegram / Viber
- **Реорганизация архива** — автоопределение уровня (корень / год / месяц), переименование папок, разделение на `*_photo` и `*_video`
- **Безопасность** — пробный прогон `--dry-run`, подтверждение перед изменениями
- **GUI-лаунчер** на Tkinter + CLI

## Установка

```bash
pip install -r requirements.txt
```

Для метаданных видео нужен `ffprobe` (из пакета ffmpeg) — добавьте его в `PATH`.

## Использование

```bash
# Сортировка по дате
python sort_media.py -s "D:\Фото\Несортированные" -d "D:\Фото\Sorted" --check-duplicates --yes

# Реорганизация архива (пробный прогон)
python reorganize_media.py -r "D:\Фото\Архив" --dry-run

# GUI-лаунчер
python launcher.py

# GUI-лаунчер без окна консоли (Windows)
wscript.exe launcher.vbs
```

## Структура

├── launcher.vbs             # запуск GUI без окна консоли (Windows)
├── assets/                  # фоновое изображение GUI
